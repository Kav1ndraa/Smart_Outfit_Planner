About the project

Smart Outfit Planner is a front-end web application that helps a user decide what to wear. It works on the user's own wardrobe and scores every possible combination of top, bottom, footwear, outerwear and accessory.

Features

  • Digital wardrobe with add, filter and delete
  • Outfit suggestions by occasion, temperature and rain
  • Color matching based on hue and neutral shades
  • Optional live weather using the Open-Meteo service
  • Saved outfits and a printable weekly plan
  • Data stays in the browser using localStorage

Technologies used

HTML5, CSS3 and JavaScript (ES6). No framework and no server are needed.

How an outfit is scored

FactorWeightWhat it checks
Color match50%Neutral shades pair with anything. Other colors score higher when close in hue or opposite on the color wheel.
Weather fit45%Total warmth of the layers compared with the target for the temperature. Below 16°C an outer layer is required.
Accessory5%Small bonus when an accessory completes the look.

Rain lowers the score of footwear that is not marked as working well in rain.
